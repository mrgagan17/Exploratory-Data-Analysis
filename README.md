# Exploratory-Data-Analysis

### Objective
The objective of this task is to perform Exploratory Data Analysis (EDA) to understand data patterns, relationships, and important features using visualizations.

---

## Datasets Used
1. Netflix Movies and TV Shows Dataset
2. Iris Dataset

---

## EDA Techniques Applied
- Histograms for numerical feature distribution
- Count plots for categorical data
- Box plots for outlier detection
- Correlation heatmap to analyze feature relationships
